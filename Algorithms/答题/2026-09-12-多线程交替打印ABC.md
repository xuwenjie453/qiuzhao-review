#题目：多线程交替打印 ABC

创建 3 个线程：线程 A 打印 `A`，线程 B 打印 `B`，线程 C 打印 `C`。要求它们严格交替输出 `ABCABCABC...`，共 10 轮。

请使用 Java 的 `synchronized + wait/notifyAll` 或 `ReentrantLock + Condition` 实现。需要处理虚假唤醒：等待条件必须使用 `while` 判断。

## 输入格式

无标准输入。轮数固定为 10。

## 输出格式

输出一行：连续的 `ABC` 共 10 次。

## 示例

```text
ABCABCABCABCABCABCABCABCABCABC
```

## 作答区

先用一两句话说明共享状态、每个线程的等待条件，以及为什么必须用 `while` 而不是 `if`。随后在代码块中完成 Java 实现。

```java
// 在此作答
class Solution{
    public int count=0;
    public char[]map={'A','B','C'};
    public Solution(){
        Thread A=new Thread(()->output(0));
        Thread B=new Thread(()->output(1));
        Thread C=new Thread(()->output(2));
        A.start();
        B.start();
        C.start();
    }
private synchronized void output(int mine) {
    for (int round = 0; round < 10; round++) {
        try {
            while (count % 3 != mine) {
                wait();
            }
            System.out.print(map[mine]);
            count++;
            notifyAll();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return;
        }
    }
}
    public static void main(String[] args){
        Solution S=new Solution();
    }
}
```
