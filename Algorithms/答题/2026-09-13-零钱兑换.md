# 题目：零钱兑换

给定不同面额硬币 `coins` 和总金额 `amount`，求凑成总金额所需的最少硬币个数；如果无法凑出，输出 `-1`。每种硬币的数量无限。

## 输入格式

第一行输入 `amount` 和硬币种数 `n`：`0 ≤ amount ≤ 10^4`，`1 ≤ n ≤ 12`。

第二行输入 `n` 个硬币面额 `c_i`：`1 ≤ c_i ≤ 10^4`。

## 输出格式

输出一个整数，表示最少硬币个数；无法凑出时输出 `-1`。

## 示例输入

```text
11 3
1 2 5
```

## 示例输出

```text
3
```

## 作答区

先用几句话说明你的状态定义、初始状态和状态转移，再完成 Java ACM 模式代码。

```java
import java.io.*;
import java.util.*;

public class Main {
    // 在此作答
    public static void main(String[] args){
        Scanner sc=new Scanner(System.in);
        int amount=sc.nextInt();
        int n=sc.nextInt();
        int[]coins=new int[n];
        for (int i=0;i<n;i++){
            coins[i]=sc.nextInt();
        }
        int[][]dp=new int[n+1][amount+1];
        for (int i=0;i<=n;i++){
            for (int j=0;j<=amount;j++){
                if (j==0) dp[i][j]=0;
                else if (i==0) dp[i][j]=-1;//当i为0时，j还不为0说明凑不出来
                else{
                    if (j>=coins[i-1]){
                        int m1=dp[i-1][j];
                        int m2=dp[i][j-coins[i-1]];
                        if (m1==-1&&m2!=-1) dp[i][j]=m2+1;
                        else if (m2==-1) dp[i][j]=m1;
                        else{
                            dp[i][j]=Math.min(m1,m2+1);
                        }
                    }else{
                        dp[i][j]=dp[i-1][j];
                    }
                }
            }
        }
        System.out.print(dp[n][amount]);
    }
}
```

dp[x][0]初始化为1，因为成功凑成了
dp[0][y]初始化为0，因为失败了
dp[0][0]也为1
