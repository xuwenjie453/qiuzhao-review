#题目：手写 LRU 缓存

设计并实现 `LRUCache`：以正整数 `capacity` 初始化。

- `get(key)`：若键存在，返回对应值并将其标为最近使用；否则返回 `-1`。
- `put(key, value)`：写入或更新键值对；容量超限时，淘汰最久未使用的键。

要求 `get` 与 `put` 的时间复杂度均为 `O(1)`。请使用哈希表定位节点、双向链表维护访问顺序（头部为最近使用，尾部为最久使用）。

## 输入格式

无标准输入。按示例顺序调用 `LRUCache` 的方法。

## 输出格式

各次 `get` 的返回值。

## 示例

```text
LRUCache cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);    // 1
cache.put(3, 3); // 淘汰 2
cache.get(2);    // -1
cache.put(4, 4); // 淘汰 1
cache.get(1);    // -1
cache.get(3);    // 3
cache.get(4);    // 4
```

## 作答区

先用两三句话说明：哈希表与链表分别保存什么、为什么更新命中也必须移动节点。随后完成 Java 实现，使用虚拟头尾节点简化边界处理。
哈希表：保存key和链表节点node
更新命中时，按照LRU算法，该key也算被访问过，所以必须移动节点

```java
// 在此作答
import java.util.*;
public class Solution{
    public class Node{
        public int key;
        public int value;
        public Node next;
        public Node prev;
        public Node(int key,int value,Node prev,Node next){
            this.key=key;
            this.value=value;
            this.next=next;
            this.prev=prev;
        }
    }
    Node head;
    Node tail;
    Map<Integer,Node>map;
    int count;
    int capacity;
    public Solution(int capacity){
        head=new Node(0,0,null,null);
        tail=new Node(0,0,null,null);
        head.next=tail;
        tail.prev=head;
        map=new HashMap<>();
        count=0;
        this.capacity=capacity;
    }
    void push(int key,int value){
        Node node=new Node(key,value,head,head.next);
        map.put(key,node);
        head.next.prev=node;
        head.next=node;
        count++;
    }
    void pop(){
        Node node=tail.prev;
        node.prev.next=tail;
        tail.prev=node.prev;
        map.remove(node.key);
        count--;
    }
    void removeToHead(Node node){
        node.prev.next=node.next;
        node.next.prev=node.prev;
        node.next=head.next;
        node.prev=head;
        head.next.prev=node;
        head.next=node;
    }
    public int get(int key){
        if (map.containsKey(key)){
            Node node=map.get(key);
            removeToHead(node);
            return node.value;
        }else{
            return -1; //不存在的值返回-1
        }
    }
    public void put(int key,int value){
        if (map.containsKey(key)){
            Node node=map.get(key);
            node.value=value;
            removeToHead(node);
        }else{
            push(key,value);
            if (count>capacity){
                pop();
            }
        }
    }
}
```
