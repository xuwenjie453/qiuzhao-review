# 题目：和为 K 的子数组

## 题面

给定整数数组和整数 `k`，统计该数组中和恰好等于 `k` 的**连续子数组**的个数。

## 输入格式

- 第一行两个整数 `n, k`（`1 ≤ n ≤ 2e5`，`-1e9 ≤ k ≤ 1e9`）。
- 第二行 `n` 个整数 `a_i`（`|a_i| ≤ 1e9`）。

## 输出格式

输出一个整数，表示和为 `k` 的连续子数组个数。

## 示例

输入：

```text
5 3
1 2 1 2 1
```

输出：

```text
4
```

### 一、这题考什么：前缀和 + 哈希表

**为什么不能滑动窗口/双指针**：滑动窗口依赖「右移右端点时窗口和单调变化」——全正数才成立。本题 |ai| ≤ 1e9 且**允许负数**，右端点右移窗口和可能变小，左端点该不该缩无法判断，双指针直接失效。

**核心推导（一句话记住）**：区间和转前缀和之差。设 P[j] = a1+…+aj（P[0]=0），则 ai..aj 的和 = P[j] − P[i−1]。要它等于 k，即 **P[i−1] = P[j] − k**。于是从左到右扫，对每个 j：在哈希表里数一数「之前出现过多少个前缀 = P[j] − k」，再把 P[j] 放进表里。一步把 O(n²) 的枚举降成 O(n)。

**手推示例**（a = 1 2 1 2 1，k = 3）：

| j | P[j] | 要找 P[j]−k | 表里命中 | 累计答案 | 放入表后 |
|---|---|---|---|---|---|
| 1 | 1 | −2 | 0 | 0 | {0:1, 1:1} |
| 2 | 3 | 0 | 1 | 1 | {0:1, 1:1, 3:1} |
| 3 | 4 | 1 | 1 | 2 | +{4:1} |
| 4 | 6 | 3 | 1 | 3 | +{6:1} |
| 5 | 7 | 4 | 1 | 4 | +{7:1} |

答案 4，对应 [1,2]、[2,1]、[1,2]、[2,1]。

**Java ACM 模式完整代码**（已编译运行，上述示例输出 4；负数/k=0/边界共 5 组测试通过）：

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer first = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(first.nextToken());
        long k = Long.parseLong(first.nextToken());

        StringTokenizer a = new StringTokenizer(br.readLine());

        Map<Long, Integer> seen = new HashMap<>();   // 前缀和 -> 出现次数
        seen.put(0L, 1);                             // 空前缀（下标 0 之前）和为 0

        long prefix = 0;                             // 前缀和值域 ±2e14，必须 long
        long ans = 0;                                // 答案最多 ~n^2/2 ≈ 2e10，也必须 long
        for (int i = 0; i < n; i++) {
            prefix += Long.parseLong(a.nextToken());
            Integer c = seen.get(prefix - k);        // 之前有多少个前缀恰等于 prefix-k
            if (c != null) ans += c;
            seen.merge(prefix, 1, Integer::sum);
        }
        System.out.println(ans);
    }
}
```

**复杂度**：时间 O(n)（每个元素一次哈希查询+一次插入），空间 O(n)（哈希表最多存 n+1 个不同前缀和）。

**Java 岗三个必踩的坑**：

1. **全 long**：前缀和最大 2e5 × 1e9 = 2e14 > int；答案最多约 n²/2 ≈ 2e10 也 > int。k 本身用 long 读入省得后面类型转换。
2. **map 初始化 put(0L, 1)**：空前缀 P[0]=0 必须先放，否则「从下标 1 开始的子数组」永远数不到——这是这题最经典的漏配 bug。
3. **ACM 输入**：n 到 2e5 用 Scanner 也能过但慢，BufferedReader+StringTokenizer 是标准姿势；输出单个数直接 System.out.println 即可。
