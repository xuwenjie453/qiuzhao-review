# 试题库纠错 QA Prompt V1

用途：对已经完成扩展的 `qiuzhao-review/试题库` 执行一次**纯纠错 QA**。

本轮不扩题、不改目录、不重编号、不重写解析，只处理：

- 确定性答案错误
- 残缺题干
- 代码错误
- SQL/计算错误
- 版本敏感错误
- 高度近义重复
- Markdown ↔ SQLite 不一致

## 核心策略

1. 结构层 100% 全量检查；
2. 高风险题 100% 全量检查；
3. 普通题分层抽查约 300 道；
4. 若普通抽样明确错误率 ≥ 2%，立即升级为 2385 道全库内容核验；
5. 即使总体错误率 < 2%，若发现系统性错误，也全查受影响范围；
6. 修复后使用第二批完全不重叠的样本复验。

## 正式题库结构冻结

```text
试题库/
├── Knowledge/
├── Algorithms/
├── Projects/
└── questions.sqlite3
```

QA 过程中不得重构该结构。
