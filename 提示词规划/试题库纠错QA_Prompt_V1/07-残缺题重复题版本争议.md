# 残缺题、重复题与版本争议

## 残缺题

全库扫描：
- xxxx / XXX
- 缺失
- 题干缺失
- 选项缺失
- 图略
- 如图
- 如下图
- 见下表
- 回忆不全
- 无法恢复

可从可靠原始题恢复 → 修。
不能恢复 → 删除。

## 重复题

只删除高度同义。

不同角度/深度/场景保留。

优先保留：
1. 题干完整
2. 选项完整
3. 答案清晰
4. 质量相同则较早ID

## 版本争议

优先：
- RFC/IETF
- Oracle/OpenJDK
- MySQL官方
- Redis官方
- Spring官方
- Python官方
- 官方AI项目文档/论文

如果确实存在版本差异：
只补最短必要条件。

不能形成唯一答案：
不自动改，列争议题。
