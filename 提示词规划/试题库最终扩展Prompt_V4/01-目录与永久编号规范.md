# 目录与永久编号规范

## 最终根目录

```text
试题库/
├── Knowledge/
├── Algorithms/
├── Projects/
└── questions.sqlite3
```

## 层级

只有：

`大类 / 英文子类 / Markdown文件`

示例：

```text
Knowledge/Java/Java-001.md
Knowledge/MySQL/MySQL-001.md
Knowledge/SystemDesign/SystemDesign-001.md

Algorithms/Array/Array-001.md
Algorithms/DynamicProgramming/DynamicProgramming-001.md

Projects/ProjectGeneral/ProjectGeneral-001.md
Projects/ProjectRAG/ProjectRAG-001.md
```

## Markdown编号

每个子类独立递增：

```text
001
002
003
```

不限制文件题量。

每次扩展只创建下一个编号文件，不向旧文件追加。

## 题号

格式：

`<SubCategory>-<FileNo>-<QuestionNo>`

例如：

```text
Java-001-001
MySQL-003-027
Array-002-015
ProjectRAG-001-009
```

## 永久性

- 文件编号不调整
- 题号不调整
- 删除后的题号不复用
- 子类名一旦确定不改
