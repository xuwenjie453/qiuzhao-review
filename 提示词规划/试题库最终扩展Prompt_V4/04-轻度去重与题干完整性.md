# 轻度去重与题干完整性

## 轻度去重

高度同义：
- 合并/保留一题

不同角度：
- 保留

不同深度：
- 保留

不同场景：
- 保留

## 追问链

拆成独立完整题。

例如：
- HashMap底层结构？
- 为什么容量2的幂？
- 扩容流程？

拆成三题。

## 组合题例外

依赖共同：
- 代码
- 图片
- 表格
- 场景

可保留一题。

## 题干完整

残缺题不要收。

选择题必须保留完整选项。

AI不得自行补缺失选项。

## 图片

优先转：
- Markdown表格
- ASCII
- 文本
- Mermaid

无法可靠转写时：
- Markdown 内嵌
- 或跳过

不创建 assets 目录。
