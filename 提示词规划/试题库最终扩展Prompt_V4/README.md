# 试题库最终扩展 Prompt V4

本 Prompt 包用于直接处理现有 `/mnt/data/试题库.zip`，将其重整并继续高密度扩展。

## 核心目标

构建一个：

- 以真实人类题干为主体
- 大而全
- 高密度
- 轻度语义去重
- 题号永久稳定
- Markdown 与 SQLite 1:1
- 解析极简
- 目录极简

的秋招技术试题库。

## 最终目录

```text
试题库/
├── Knowledge/
├── Algorithms/
├── Projects/
└── questions.sqlite3
```

正式题库中不保留 README、统计、来源、日志、Prompt、报告、临时脚本等管理文件。

## 文件说明

- `00-最终主Prompt.md`：总控 Prompt，可直接交给具备网页搜索、文件操作、SQLite、Python 能力的 Agent。
- `01-目录与永久编号规范.md`：三层目录、文件编号、题号规则。
- `02-SQLite规范.md`：极简数据库结构与一致性校验。
- `03-真人题抓取与两轮扩展.md`：2020年至今真人题、牛客优先、408 全量选择题、两轮扩展。
- `04-轻度去重与题干完整性.md`：题干优先、轻度去重、追问链拆分。
- `05-答案解析与算法项目规则.md`：极简答案解析、算法/项目分类。
- `06-迁移与最终清理.md`：旧题编号迁移、原地扩展、最终目录清理。
- `07-完成报告模板.md`：任务结束后在对话中输出，不写入正式题库。
- `主Prompt_纯文本.txt`：主 Prompt 纯文本副本。

## 默认输入

`/mnt/data/试题库.zip`
