# 交付产物检查

最终应该能看到至少这些类别的变化：

```text
Review node shape schema/service/sync/UI
Notebook independent DB/store/service
NotebookGraph domain/UI
Notebook CLI/tree
Tests
Docs
```

不应该看到：

```text
Notebook tables in scheduler.sqlite3
Notebook membership in Review graph_inheritance
NotebookGraph rows in Review graphs table
Review user_graph_scheduler handling NotebookGraph
Question bank writes caused by Notebook
```

# 最终演示脚本

至少人工演示一次：

1. 打开已有 Review 图，确认旧形状不变；
2. 把一个 Review CENTER 改圆形；
3. 把一个 Review EXPLANATION 改三角形；
4. 重启后形状仍在；
5. 创建 Notebook `阅读方法`；
6. 创建两张 NotebookGraph；
7. 一张放入 `阅读方法`，一张保持未归档；
8. 两张图均可拖节点、拖画布、改 shape；
9. 执行 `notebook tree`，看到 Notebook 与未归档；
10. 在 Review 系统创建同名 USER_AUTHORED 图；
11. 再执行 `notebook tree`，结果完全不受影响；
12. 删除 Notebook，原两张 NotebookGraph 不丢失，归档图转入未归档。

如果以上演示和自动测试都通过，才视为 V1 完成。
