# 架构冻结与目录边界

## 内容层
- `试题库/`：真人问题空间与正式 Probe Pool。
- `资料库/`：教学内容源。

## 控制层
- Goal Compiler：自然语言目标 → 结构化 Goal；不排每日任务。
- Temporal Scheduler：只决定下一项 TaskIntent；不教学。
- Learning Engine：只负责把不会变成当前可独立完成。
- Review Engine：只负责检测已学内容当前是否仍可提取。
- Review Probe Compiler：只把复杂学习成果压缩成长期 Capsule。
- Expansion Hub：只负责扩展 Goal / Materials / QuestionBank。

## 数据层

```text
复习体系/
├── scheduler.sqlite3
├── Knowledge/knowledge.sqlite3
├── Algorithms/algorithms.sqlite3
└── Projects/projects.sqlite3

资料库/materials.sqlite3
试题库/questions.sqlite3
```

## 硬规则
1. 调度数据库只放根目录。
2. Knowledge/Algorithms/Projects 的数据库分别放各自目录。
3. materials.sqlite3 只属于资料库。
4. questions.sqlite3 只属于试题库。
5. 不创建一个 all.sqlite3 合并所有数据。
6. 需要统一读取时通过 `ATTACH DATABASE`。
7. 跨库写尽量保持单库事务，避免复杂多库原子写。
8. Scheduler 不写教学答案。
9. Learning Engine 不决定未来复习日期。
10. Review 成功后不能继续多测。
11. AI 临时题永不进入 questions.sqlite3。
