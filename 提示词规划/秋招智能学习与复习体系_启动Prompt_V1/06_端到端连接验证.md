# 端到端连接验证

目标：确认 Mac daemon ↔ iPad 的图数据与批注链路通畅。

## 1. 链路

```bash
node DualEnd-Mac/bin/qreview-dual.mjs daemon status
# sessions ≥ 1 → iPad 已连；iPad 端徽章应显示"已连接"
```

## 2. 图数据

```bash
node DualEnd-Mac/bin/qreview-dual.mjs graph snapshot   # 有节点、revision 正常
```

无活跃 round 时用临时题开一轮验证（示例用 `DualEnd-common/fixtures/` 内容自造 open.json）：

```bash
cat > /tmp/open.json <<'EOF'
{ "question_ref": {"source": "QUESTION_BANK", "question_key": "qb:smoke",
                   "source_id": "smoke"},
  "question_body_markdown": "## 冒烟\n\n双击节点进入 Reader，书写一笔后返回。",
  "ai_title": "连接冒烟" }
EOF
node DualEnd-Mac/bin/qreview-dual.mjs question open --json /tmp/open.json
```

## 3. iPad 端人工检查（30 秒）

1. 问题图页面出现节点，徽章"已连接"；
2. 双击节点 → 进入 Reader，页面适宽、可纵向滚动；
3. Pencil 写一笔 → 返回；重进节点笔迹仍在原位；
4. Mac 侧再 `graph snapshot` 无异常、`daemon status` 无错误会话。

## 4. 探针快照含义（Debug 构建）

`hover-probe.jsonl` 中的 `viewport-first-fit`（Reader 视口已按适宽比应用）、
`render-finished`（PencilKit 异步渲染完成）正常出现即 Reader 链路健康；
`canvas_zoom` 应等于适宽比（横屏 ≈1.98）且与镜像层 transform 一致。

验证完毕：冒烟轮次若无需保留，`question close --round <id>` 收尾。
