# 秋招智能学习与复习体系 · 启动 Prompt V1

本包回答一个问题：**新 AI 接管后，如何把整个系统启动起来、自检通过、并在异常时排障。**

## 与 RuntimePrompt_V1 的分工

| 包 | 职责 |
|---|---|
| **本包（启动）** | 环境 bring-up：资产自检、学习核心健康、双端（Mac daemon + iPad App）启动、连接验证、故障排查 |
| `秋招智能学习与复习体系_RuntimePrompt_V1` | 学习会话运行契约：调度、三引擎教学、复习、事件落库、自然语言控制 |

先跑通本包，再按 RuntimePrompt_V1 运行学习会话。

## 何时使用

1. 新 AI 第一次接管本工作区，需要把系统跑起来；
2. 长时间未用 / 重启机器 / 换设备后恢复环境；
3. 双端（daemon / iPad / 同步 / Reader）出现异常，需要定位。

## 执行顺序

```text
01_启动总控Prompt.md        ← 必读：系统组成与决策树
02_环境与资产自检.md
03_学习核心自检.md
04_双端Mac守护进程.md        ← 需要双端时
05_iPad端构建安装.md         ← 需要双端时
06_端到端连接验证.md         ← 需要双端时
07_故障排查速查.md           ← 异常时查表
08_启动完成判定.md           ← 收尾
```

## 绝对约束

- 本包只做**启动、验证、诊断**；禁止借"启动"重设计架构、改 schema、动正式题库。
- 一切状态以 SQLite / 文件 / `daemon status` 实测为准，不依赖聊天记忆。
- daemon 未启动**不阻断学习**——学习核心独立于双端运行。
- 获取**真实当前日期**（`date`），不要用记忆中的日期。
