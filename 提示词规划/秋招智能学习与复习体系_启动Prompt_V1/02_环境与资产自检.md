# 环境与资产自检

## 资产清单与检查

| 资产 | 路径 | 缺失处置 |
|---|---|---|
| 控制层 | `scheduler.sqlite3` | ⛔ 禁止自造——停止并报告用户 |
| 三引擎库 | `Knowledge/` `Algorithms/` `Projects/` 各 `*.sqlite3` | ⛔ 同上 |
| 正式题库 | `试题库/questions.sqlite3` | ⛔ 只读资产；缺失报告用户 |
| 资料索引 | `资料库/materials.sqlite3` | ✅ `python3 学习系统/cli.py expand-materials` 重建（本地需先放入资料） |
| 学习系统代码 | `学习系统/cli.py` | 应随仓库存在；异常用 `git status` 检查工作区 |
| 双端状态 | `系统数据/dual-end/`（不入 git） | 由 daemon 首次启动自动创建 |

```bash
date                                    # 真实日期
python3 学习系统/cli.py status          # Goal/三引擎/复习预算
python3 学习系统/cli.py integrity       # 五库 integrity + foreign_key（异常先备份再诊断）
```

## 判读

- `status` 能输出 ACTIVE Goal 与三引擎摘要 → 学习核心健康。
- 无 ACTIVE Goal → 提示用户，按 RuntimePrompt_V1 `10-创建与调整Goal.md` 走 Goal Compiler。
- `integrity` 报错 → 先 `cp` 备份相关库再按 RuntimePrompt_V1 `14-数据库读写与QA.md` 处理，不静默覆盖。

## 环境要求

- macOS + python3（学习核心）；Node ≥ 20（daemon）；Xcode + 已配对 iPad（双端真机，可选）。
- 资料库内容为本地资产（不入 git）：新机器需用户自行放回资料后 `expand-materials`。
