# 故障排查速查

按症状查表；处置前先复现并取实证（命令输出 / 日志 / 采样），不凭记忆猜。

| 症状 | 最可能原因 | 处置 |
|---|---|---|
| iPad 一直"正在连接…"（真机） | daemon 未启动 / 不在同一局域网 / 本地网络权限被拒 | `daemon status`；检查同网段；权限被拒→iPad 设置→隐私→本地网络，App 内徽章可点跳转 |
| 模拟器 App 永远连不上 | WS 传输要求 wifi 接口，模拟器 lo0 不满足 | **已知限制，非故障**；模拟器验证用离线播种（05 号） |
| `devicectl install` 报 Connection reset | 连接抖动 / 设备锁屏 | 重试；设备解锁并信任 |
| 双击节点卡死 / 界面无响应 | `@Published` 同值写入 × updateUIViewController 反馈死循环（已于 v3 修复，若有复发即回归） | 复现后 `sample <pid> 3 -file /tmp/s.txt` 看主线程栈；跑 `PencilLoopGuardTests`；对照 v3 包 06 号补记 |
| hover 预览/书写中墨迹错位 | 双重视口基准（已于 v3 修复，复发即回归） | 用探针四角协议取证（v3 包 04 号），核对 `canvas_zoom` 是否唯一显示比例 |
| 历史笔迹与正文错位 | 有人动了 canonical 坐标或做了"数据迁移"（禁止项） | `git log` 查 Reader/排版改动；canonical 595.92×842.88 与 `layoutSignature` 不得变更 |
| daemon 报锁 / 双开 | 残留 `daemon.lock` | `ps` 确认无进程后删 `系统数据/dual-end/runtime/daemon.lock` 再启 |
| daemon 起不来 | Node 版本 / 端口占用 | `node -v`（≥20）；`lsof -i` 查占用；看 `系统数据/dual-end/logs/` |
| `cli.py status` 报库损坏 | SQLite 异常 | 先备份库文件，再 `integrity` 诊断，按 RuntimePrompt 14 号处理 |
| `materials.sqlite3` 缺失 / 检索空 | 本地资料未放 / 索引未建 | `expand-materials` 增量重建；不要重做架构 |
| Reader 打开但页面不适宽 / 不能滚 | `contentSize` 单位被改（须 display 单位 = canonical×z） | 跑单测 `testDisplayContentSizeUsesDisplayUnits`；对照 v3 包 05 号 §二顺序 |
