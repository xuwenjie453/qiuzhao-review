# 学习核心自检

学习核心不依赖双端，任何时候都可独立运行。

## 启动检查

```bash
python3 学习系统/cli.py status    # ACTIVE Goal / Review capsules / 三引擎状态
python3 学习系统/cli.py task      # Scheduler 当前选中的 TaskIntent（只读预览）
```

## 判读要点

- Active Goal 的 `end_date` 与真实日期对比，判断阶段（Coverage 前期/中后期）。
- `due-now` 只是候选数，**不是必须清偿的债务**，不向用户展示为清单。
- 只读摘要即可，禁止把全部 Events 拉进上下文。

## 进入学习会话

核心健康后，会话行为全部交给 RuntimePrompt_V1：

```text
00-运行总控 → 02-开始学习 → 对应引擎 Prompt → 09/14（写库纪律）
```

本包到此为止，不重复其规则。
