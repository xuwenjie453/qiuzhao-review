# iPad 真机验收提示词

自动化测试通过后，使用已配对并开启开发者模式的 iPad 真机验收，不得仅凭模拟器截图宣布完成。

## 安装和启动

1. 确认 Xcode 选中真实 iPad，而非 Simulator。
2. 使用项目已有 Team、签名证书和 provisioning profile。
3. Build & Run 最新代码。
4. 启动 Mac daemon，确认双端可同步。
5. 保留 Xcode 控制台日志，关注 Reader configure、zoom、offset 和 PencilKit 日志。

## 横屏场景

1. 将 iPad 旋转为横屏。
2. 在问题图双击一个有正文的节点。
3. 确认页面立即按宽度铺满，不需要捏合。
4. 确认第一页顶部可见。
5. 上下滑动连续阅读，左右滑动不移动、不回弹。
6. 双指捏合，确认页面大小不变。

## 书写场景

用 Apple Pencil 在正文中间、左留白、右留白、页面顶部和页面底部画短线；再尝试页面外灰色区域。前五处必须有效，最后一处必须无效，并确认悬停点、落笔点和线条起点重合。

## 旋转场景

在第一页中部写一笔，滚动到第二页中部，旋转到竖屏再回到横屏。检查阅读位置合理保持，已有和新写笔迹始终与内容对齐。退出节点后再次进入，确认笔迹不偏移。

## 报告格式

每个场景记录设备、系统、方向、预期、实际、是否通过、截图或日志路径。
