# 真机 Apple Pencil 验收提示词

必须使用真实 iPad 和 Apple Pencil。记录设备型号、iPadOS 版本、方向、节点 ID、页面编号和截图。

## 基础场景

1. 打开已有节点，等待 Reader 完全显示。
2. Pencil 不接触屏幕，只在页面上方、中央、下方悬停。
3. 记录 hover 预览是否和笔尖重合。
4. 接触屏幕画短线，移开 Pencil。
5. 确认正式笔迹位置正确且 hover 结束后不跳动。

## 新解释节点场景

1. Mac 生成并推送新的解释节点。
2. iPad 收到节点后立即进入。
3. 分别在进入后立即、500ms、1s 悬停测试。
4. 退出并重新进入同一节点，再重复测试。

## 几何场景

在同一页面上分别测试：

- 页面上方笔迹；
- 页面中部笔迹；
- 页面下方笔迹；
- 左右留白笔迹；
- 多页文档第二页和末页。

如果上方和下方仍出现相反方向偏移，不得判定通过。

## 交互回归

- 横屏页面仍按宽度铺满；
- 页面只能上下滚动；
- 双指捏合无效；
- 页面外不能写；
- 横竖屏切换后位置和笔迹不变；
- 返回问题图后重新进入不产生偏移。
