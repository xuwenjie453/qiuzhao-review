# 秋招智能学习与复习体系 Runtime Prompt V1

这是运行使用包，不是系统构建包。

适用：系统目录、SQLite、题库、资料库已经存在；用户在 Codex / ZCode 等 Agent 环境中通过长期对话学习；新 AI 需要快速接管并正确运行。

核心入口：
- 开始学习
- 继续学习
- 今天多做一点算法
- 只复习
- 制定/调整目标
- 扩展资料库
- 今天先到这里
- 恢复上次学习

核心纪律：
1. 这是 Agent-native 学习工作区，不是传统软件项目。
2. 不创建 Web/桌面 App，除非用户明确要求。
3. 用户主要负责看、想、说、写；AI负责读取状态、调度、教学、评估、记录。
4. 时间用于日期与调度，不用于打断思考。
5. Learning Verified 后才进入 Review。
6. Review 是轻量 Probe；成功一次立即结束。
7. 正式题库禁止被 Runtime Agent 擅自扩展。

建议把 `AGENTS.md` 放在学习工作区根目录，其余文件放 `复习体系/Prompts/Runtime/`。
