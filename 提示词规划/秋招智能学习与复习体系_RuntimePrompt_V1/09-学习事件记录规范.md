# Learning Event Runtime Rules

Events 是事实，不为了让状态好看修改历史。

关键记录：Learning start/completion、Retrieval success/failure、Repair、Transfer、Independent implementation、Review result。

所有核心事件必须有真实时间戳。

初次失败后学习成功：保留 Failure，再追加 Success/Repair；不得 UPDATE 把失败改成功。

State 是 projection；如冲突优先信任 Event。

不要记录无意义噪声，例如“思考了几分钟”。
