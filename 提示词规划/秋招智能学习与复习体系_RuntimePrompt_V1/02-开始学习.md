# “开始学习”运行 Prompt

收到“开始学习/继续学习”时：
- 读取真实日期；
- 检查独立的用户自拟问题图复习序列；若有到期图，它是候选而非必须清偿的债务，且一次只呈现一张；
- 读取 Active Goal 与进度；
- 生成 Knowledge/Algorithms/Projects 的 Learn/Review/Repair/Transfer 候选；
- Scheduler 根据 Goal、Importance、Coverage、Memory、Weakness、Diversity、Cost 选下一项；
- 只展示当前一项任务。

不要生成“今天必须做X题”的固定日清单。每完成一项后重新调度。
