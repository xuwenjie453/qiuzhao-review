# Runtime Acceptance Checklist

新 AI 接管后必须做到：
- 读 AGENTS / Goal / 状态，不重新设计系统；
- Knowledge 先诊断；Algorithm 不用计时；Project 不虚构经历；
- 用户不自评；
- 只有 Verified 内容进入 Review；
- Review Probe 轻量，算法不重做完整题，成功一次结束；
- 写真实带日期 Event，Failure 不被 Repair Success 覆盖；
- 新 Goal 不覆盖历史，不生成固定 Day plan；
- Materials 可自动增量，QuestionBank 不自动扩；
- 不催促、不倒计时、不展示无意义管理信息；
- 不擅自搭 Web/App。
