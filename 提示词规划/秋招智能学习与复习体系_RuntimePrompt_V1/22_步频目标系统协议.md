# 步频目标系统协议（PaceGoal V1）

PaceGoal 用于“每天稳定推进明确数量的有意义单位”。它和普通 Goal、截止日期、学习时长、Review 时序完全独立；数据仅保存在根 `scheduler.sqlite3` 的 `pace_*` 表中。

## 一、必须遵守的语义

- 每日只记录真实完成量；昨日和上个时段的未完成量**绝不**结转或追加。
- 推送是中性的节奏报告，不得出现“欠、还差、失败、必须、落后、补做”等催促或惩罚语言。
- AUTO 只由真实系统事件增加。`EXPLANATION_NODE_CREATED` 由守护进程在 `EXPLANATION` canonical commit 成功后触发，并按 node ID 幂等；不得通过查询历史节点数量补造事件。
- MANUAL 仅在用户明确报告系统外行为时增加；不得因为用户说“我会了”自动计数。
- 有限目标达到总步骤后自动 `COMPLETED`，保留历史并退出后续推送；暂停目标保留历史但不计数、不推送。
- 历史日记录是事实，后续改每日目标或分配时不得重写。

## 二、自然语言映射

用户说“每天新增 8 个解释节点，早上 3、下午 3、晚上 2”，创建：

```json
{
  "title": "新增解释节点",
  "daily_target": 8,
  "period_allocation": {"morning": 3, "afternoon": 3, "evening": 2},
  "progress_source": "AUTO",
  "detector_type": "EXPLANATION_NODE_CREATED",
  "lifecycle_type": "CONTINUOUS"
}
```

可识别的内部事件使用 `AUTO`；系统无法观察的背单词、线下练习等使用 `MANUAL`。用户说“日语单词完成了 5 个”时，按发生时刻所属时段执行一次 `pace-goal-progress --increment 5`。

有限目标例子：`完成 15 个专题、每天 1 个` → `lifecycle_type=FINITE`、`total_steps=15`。不确定单位或总量时先向用户澄清，禁止猜测。

## 三、时段与推送

时段为上午/下午/晚上；默认归属：`00:00–12:59 → 上午`、`13:00–18:59 → 下午`、`19:00–23:59 → 晚上`。这样早于 09:00 或晚于 22:30 的真实完成也不会丢失。

守护进程运行时，在 Mac 通知中心按以下时刻发送**一条聚合消息**：

```text
09:00  早间步频：今日总量 + 上午进度
13:00  午间步频：今日累计 + 上午事实 + 下午目标
19:00  晚间步频：今日累计 + 下午事实 + 晚上目标
22:30  今日步频总结：三个时段的实际量；有限目标的总进度/完成状态
```

守护进程重启不会重复发送同一日期/时段的通知；错过的时段不补发。iPad Reader 保持问题图和资料阅读职责，V1 的主动通知发送至 Mac 通知中心。

## 四、Agent CLI

所有写入均通过 CLI/服务，禁止直接写 SQLite：

```bash
# 创建和查看
python3 学习系统/cli.py pace-goal-create --json /tmp/pace-goal.json
python3 学习系统/cli.py pace-goal-list [--status ACTIVE|PAUSED|COMPLETED]
python3 学习系统/cli.py pace-goal-summary [--date YYYY-MM-DD]
python3 学习系统/cli.py pace-goal-daily --id <goal_id> [--date YYYY-MM-DD]

# 手动目标：用户明确汇报后才调用
python3 学习系统/cli.py pace-goal-progress --id <goal_id> --increment 5 [--note "... "]

# 调整与状态
python3 学习系统/cli.py pace-goal-update --id <goal_id> --json /tmp/patch.json
python3 学习系统/cli.py pace-goal-status --id <goal_id> --status paused|active

# 守护进程内部使用；Agent 不得手动伪造 AUTO 事件
python3 学习系统/cli.py pace-goal-record-auto --detector EXPLANATION_NODE_CREATED --source-ref <node_id>
python3 学习系统/cli.py pace-goal-notify --due
```

`pace-goal-notify --dry-run --slot MORNING` 只预览内容，不记录已推送。守护进程每 30 秒检查一次且只在目标时刻后的 3 分钟窗口发送。
