# Codex / ZCode Runtime Notes

本系统默认以 Agent-native 方式运行。

Codex：根级 `AGENTS.md` 用于持久化工作区规则。

ZCode：Workspace `AGENTS.md` 会在新任务中作为项目级指令来源；常用 Runtime Prompt 可保存成 Workspace Commands，例如 `/study`、`/review`、`/status`、`/expand-materials`、`/resume`。

ZCode 自带 `/goal` 属于会话级目标能力；本系统的长期学习 Goal 仍以 `scheduler.sqlite3` 的 Goal Compiler 为事实来源。不要把工具自带 session goal 与长期学习 Goal 混为一个数据对象。

无论在哪个平台：
> 对话是 UI，SQLite 是长期状态，题库/资料库是内容资产，Prompt 是行为协议。
