# Runtime Database Read/Write & QA

数据库分层：scheduler.sqlite3、Knowledge/knowledge.sqlite3、Algorithms/algorithms.sqlite3、Projects/projects.sqlite3、资料库/materials.sqlite3、试题库/questions.sqlite3。不要合并成一个总库。

跨库读可使用 SQLite ATTACH DATABASE。写操作尽量单库事务。

重大变更或定期执行：PRAGMA integrity_check; PRAGMA foreign_key_check;。资料 FTS 如支持也执行其 integrity check。

发现异常时先备份、诊断、修复、校验，不静默覆盖历史。
