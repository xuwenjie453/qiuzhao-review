# Review Capsule Runtime Compiler

只在 LEARNING_VERIFIED 后运行。

输入：newly learned / repaired / fragile / stable prerequisites / source questions / learning evidence。

去除已长期稳定前置与低价值偶然细节；合并过碎技能。例如 deque.append + popleft → Python/DequeBasicOperations。

算法 Capsule 必须记录：target skill、非目标技能、required_context、allowed_probe_types、response_budget。

输出写各引擎 review_capsules 并激活 scheduler schedule；不得写正式题库。
