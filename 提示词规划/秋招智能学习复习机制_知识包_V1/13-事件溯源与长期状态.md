# Event Sourcing 与长期学习状态

长期最重要的数据不是：

> 当前 mastery 数值

而是：

> 真实发生过的带日期学习事件。

## 1. Events Are Facts

例如：

```text
2026-09-05 LEARNING_VERIFIED
2026-09-08 REVIEW_SUCCESS
2026-09-15 REVIEW_FAILURE
2026-09-15 REPAIR_SUCCESS
```

这些原则上不可变。

## 2. State Is Projection

Current State：

- stability；
- difficulty；
- last success；
- failure count；
- current stage；

都可以由历史事件重建。

## 3. 为什么重要

未来可能：

- 调度算法升级；
- Prompt升级；
- 记忆曲线升级；
- AI评分逻辑升级。

如果只存最终 S：

> 过去数据无法重新计算。

如果保留 Events：

> Replay 即可。

## 4. 半年中断

历史不会消失。

系统根据：

- 历史成功；
- 历史失败；
- elapsed time；

重新估计。

这使系统具备长期使用价值。

## 5. 数据最小化

不要记录没有实际用途的行为噪声。

重点记录：

> 对未来能力估计和调度真正有信息价值的事件。
