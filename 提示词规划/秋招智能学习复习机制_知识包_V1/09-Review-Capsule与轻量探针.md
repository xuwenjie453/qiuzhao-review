# Review Capsule 与轻量探针

整个复习体系最重要的原则：

> Review is a Probe, not a Re-learning Session.

## 1. 原题不能自动进入复习队列

一道完整题只是：

> 学习载体

Learning 结束后应提取：

> 真正新学、修复或仍脆弱的最小能力。

## 2. Review Probe Compiler

流程：

```text
Learning Complete
→ 提取新能力
→ 去除已Stable前置
→ 合并过碎技能
→ 判断是否值得长期保持
→ 生成 Review Capsule
```

## 3. Review Capsule 保存什么

- target
- engine
- must_retrieve
- known_failure_modes
- allowed_probe_types
- required_context
- response_budget
- source_questions
- eligibility_evidence

它不是固定题。

它是：

> 未来如何有效测试这个能力的规格。

## 4. 普通 Review 的目标

用最小成本引导大脑完成一次真实提取。

### Knowledge
一句/一小段解释。

### Algorithms
局部代码/结构任务。

### Projects
一个短工程决策。

## 5. 成功路径

```text
Cold Probe
→ Success
→ 记录事件
→ 立即结束
```

不追加第二题确认。

真正的确认来自：

> 未来另一个日期的再次成功。
