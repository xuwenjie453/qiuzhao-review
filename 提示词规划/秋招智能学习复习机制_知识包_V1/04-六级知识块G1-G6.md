# 六级动态知识块 G1～G6

知识块不是按固定字数划分，而是按：

> 知识图半径

定义。

## G1 Point

只修一个细节。

适合：

> 整体会，只忘局部。

例如：

> 只忘 RC / RR 下 Gap Lock 差异。

## G2 Core｜默认

最小充分知识结构。

通常包含：

- 当前核心；
- 缺失的必要前置；
- 1～3 个容易混淆概念；
- 原因/机制；
- 一层追问。

绝大多数陌生题从 G2 开始。

## G3 Cluster

用户缺的不是一个点，而是局部知识簇。

例如：

- Record Lock；
- Gap Lock；
- Next-Key Lock；
- S/X Lock；

整体混乱。

## G4 Subsystem

一套机制整体陌生。

例如：

> MySQL Concurrency Control

包含：

- Isolation；
- MVCC；
- Read View；
- Locks；
- Phantom。

## G5 Module

整个模块缺少结构。

例如：

> MySQL Transactions

包含多个子系统。

## G6 Domain Map

整个领域需要重建。

G6 不是一篇巨长文章，而是：

> 领域地图 + 学习拆分计划。

例如：

```text
MySQL
├── Index
├── Transactions
├── Locks
├── Logs
├── Optimization
└── Replication
```

然后继续拆回 G4/G3/G2 学习。

## 自动升降级

系统默认 G2。

如果发现用户前置很强：
→ G1。

如果连续暴露多个基础缺口：
→ G3/G4/G5/G6。

用户通常不需要手动选择粒度。
