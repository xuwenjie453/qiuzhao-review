# 秋招智能学习与复习机制｜知识包 V1

本知识包不是构建 Prompt，而是对整套学习、复习、记忆与调度机制的知识化沉淀。

它回答：

- 为什么系统要把 Learning 与 Review 分开；
- Knowledge / Algorithms / Projects 为什么需要不同学习引擎；
- G1～G6 动态知识块如何工作；
- 算法为什么要拆成技能模块；
- Review Capsule 为什么不能等同于原题；
- 为什么复习必须轻量；
- Difficulty / Stability / Retrievability 如何表示长期记忆；
- 为什么 Goal 与日期共同决定复习时机；
- 为什么历史 Event 比当前 mastery 数值更重要；
- 为什么资料库需要 Hybrid RAG；
- 为什么用户应尽量少做自评、模式选择和时间管理。

## 一句话定义

> 这套体系以真实试题为能力空间，以资料库和 AI 为动态教学源，以 Learning Engine 建立能力，以 Review Capsule 做跨日期的轻量主动检索，以长期 Event History 建模个人记忆，并由 Goal-aware Temporal Scheduler 决定每一个时点最值得投入注意力的学习任务。
