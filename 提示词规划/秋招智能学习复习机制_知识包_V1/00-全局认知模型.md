# 全局认知模型

## 1. 学习系统不是“刷题器”

系统面对的核心问题不是：

> 今天刷多少题？

而是：

> 在当前目标、已有知识、过去学习历史和真实日期下，下一单位注意力应该投入在哪里，才能获得最高的长期收益？

因此系统被分成四层：

```text
Goal
↓
Temporal Scheduler
↓
Learning / Review
↓
Knowledge / Algorithms / Projects
↓
Events / States
↓
再次反馈给 Scheduler
```

## 2. 内容资产与能力资产分离

### 试题库
表示真实问题空间。

### 资料库
表示教学材料空间。

### 学习状态
表示用户个人能力空间。

不能把三者混在一起。

## 3. 三类能力

### Knowledge
目标：理解并解释。

### Algorithms
目标：拆解并实现。

### Projects
目标：分析、设计、权衡和防守方案。

因此它们必须使用不同学习引擎。

## 4. 用户与 AI 的职责

用户主要做：

- 看；
- 想；
- 说；
- 写。

AI负责：

- 诊断；
- 选择教学粒度；
- 调用资料；
- 生成知识块；
- 评估回答；
- 维护状态；
- 生成复习探针；
- 调度学习；
- 写事件。

系统应尽量减少“管理学习”本身的负担。
