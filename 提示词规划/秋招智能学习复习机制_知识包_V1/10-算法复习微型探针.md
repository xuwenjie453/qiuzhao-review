# Algorithm Review Micro Probes

算法完整题太长，因此普通复习必须模块化。

## 1. 基本规则

如果本次只复习：

> Tree Construction

那么：

- TreeNode 定义必须给；
- 输入结构必须给；
- 函数签名必须给；
- 其他不测试能力必须提供。

只让用户完成：

> 构造逻辑。

## 2. Probe 类型

### Explain
解释核心不变量。

### API Recall
例如 set / deque / heapq 的关键操作。

### Complete
补 3～10 行关键代码。

### Construct
构造树、链表、图等。

### Boundary
只写二分边界或窗口收缩。

### State Definition
写 DP 状态与转移。

### Trace
推演一小段执行。

### Repair
修复一个典型 bug。

### Skeleton Fill
给完整骨架，只填核心函数。

## 3. Context Completion Rule

Probe 必须明确：

### 测什么
Target Skill。

### 不测什么
所有其他技能。

### 因此必须提供什么
完成本目标所需的完整上下文。

这样复习才具有诊断效度。

## 4. Component 与 Integration

### Component Stability
高频、轻量。

### Integration Stability
多个技能组合成完整解决方案。

完整 LeetCode/ACM 题：

> 低频 Integration / Transfer Review

不是普通 Review。
