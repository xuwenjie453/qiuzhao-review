# Algorithm Learning Call Stack 与动态支架

## 1. 学习调用栈

用户始终围绕原题学习。

例如：

```text
Original Problem
→ Tree DFS
→ Recursive Return
→ Python Recursion
```

解决最底层：

```text
Python Recursion ✓
↑
Recursive Return ✓
↑
Tree DFS ✓
↑
Original Problem
```

系统不能让用户感觉自己不断被送去不同课程。

## 2. 不采用时间触发

禁止：

> 想了10分钟还不会，所以自动提示。

用户可以无限思考。

AI只根据：

- 用户语言；
- 代码；
- 主动求助；

判断支架。

## 3. 支架梯度

可能包括：

- H0 无提示；
- 方向性问题；
- Pattern 提示；
- 不变量；
- 状态定义；
- 伪代码；
- Skeleton；
- 部分代码；
- Worked Example。

但这些不需要用户手动选择 H1/H2。

## 4. 不同练习形式

根据真正缺口可以使用：

- Trace；
- Parsons；
- Fill Gap；
- Skeleton；
- Blank Code。

最终必须回到：

> 无辅助独立实现。

## 5. 完成标准

Algorithm Learning Complete 必须至少满足：

- 原题独立写出；
- 实际运行；
- 样例/边界通过；
- 必要时对拍；
- 一次短迁移验证。

随后进入 Review Probe Compiler。
