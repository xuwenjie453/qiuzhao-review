# 心流与交互原则

用户提出的重要原则：

> 心流的关键之一，是减少对自己的持续关注。

因此系统应尽量减少元操作。

## 1. 不要求用户频繁自评

不弹：

- 我掌握度1～5是多少？
- 这题Easy/Hard吗？
- G2还是G3？
- 几天后复习？
- 今天做多少题？

AI从真实表现估计。

## 2. 不用时间打断思考

学习时：

> 用户想多久都可以。

AI不因为沉默主动：

- 倒计时；
- 催促；
- 弹提示；
- 自动显示答案。

## 3. 清晰单一当前任务

一次只让用户关注：

> 当前问题。

系统内部可以很复杂。

用户界面应很简单。

## 4. 即时但克制反馈

回答后：

- 指出关键缺口；
- 给必要教学；
- 继续下一步。

不要每次都展示复杂分析雷达图。

## 5. Challenge-Skill Balance

教学支架自动调整：

- novice → 更多结构；
- 熟练 → 更少冗余；
- 完全会 → 直接通过。

## 6. 自然语言优先

用户可以说：

- 我继续想，不要提示；
- 给点方向；
- 这部分我会；
- 再展开一点；
- 今天想学MySQL；
- 明天面试。

系统将其转成内部控制，不要求用户管理参数。
