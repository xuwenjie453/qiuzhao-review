# V1 机制冻结清单

以下原则视为 V1 顶层设计冻结。

## Learning

- Learning 与 Review 分离；
- 只有 Learning Verified 才进入 Review；
- AI负责掌握判断；
- 用户不手动打分；
- 学习不使用超时触发；
- 支架随表现动态调整。

## Knowledge

- 题目先诊断；
- 资料负责教学；
- G1～G6 六级粒度；
- 默认 G2；
- Repair 优先于机械升级；
- 真人验证题优先；
- AI临时验证题不入正式题库；
- 短巩固后切换主题。

## Algorithms

- 算法题视为技能模块组合；
- 稳定骨架 + 动态技能图；
- Learning Call Stack；
- 缺什么补什么；
- 最终必须独立实现；
- 普通复习不重做完整算法；
- Component Review 轻量；
- Integration Review 低频。

## Projects

- 学工程方案，不虚构项目经历；
- PSB；
- 多维内部诊断；
- 用户只看关键缺口。

## Review

- Review 是 Probe；
- 原题不自动进入复习；
- Review Capsule；
- 成功一次立即结束；
- 失败按程度分流；
- Repair 后成功仍保留原 Retrieval Failure。

## Memory

- D/S/R 模型；
- 日期动态计算 R；
- 曾经掌握不等于永久掌握；
- 事件历史比当前状态重要；
- State 可 Replay 重建。

## Scheduler

- Goal-aware；
- Due 不是必须清空；
- Review 与 New Learning 统一竞争；
- Coverage Goal 保护新学习；
- Sprint 提高 Retention / Weakness / Importance；
- 半年后用 Reactivation。

## UX

- 少选择；
- 少自评；
- 不倒计时；
- 不催促；
- 自然语言覆盖；
- 内容心流优先。
