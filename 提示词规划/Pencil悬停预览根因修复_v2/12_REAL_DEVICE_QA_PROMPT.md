# 实体 iPad + Apple Pencil 验收提示词

必须记录设备型号、iPadOS、Pencil 型号、应用 build、节点 ID、页面编号和方向。

## Hover 三点测试

在同一页上方、中部、下方悬停，分别从远到近移动 Pencil：

- 预览中心是否与笔尖重合；
- 是否存在右移；
- 上方和下方是否仍方向相反；
- 移开后页面是否恢复；
- hover 期间 drawing 哈希和 revision 是否不变。

## 正式书写测试

在以下位置各画一条短线：

```text
正文左侧、正文中间、正文右侧
页面顶部、页面底部
第一页、第二页或末页
```

确认落笔与文字位置一致，退出后重新进入仍一致。

## 生命周期测试

- 新解释节点收到后立即进入；
- 等待 500ms/1s 后进入；
- 同一节点退出再进入；
- 横屏 → 竖屏 → 横屏；
- 滚动后再 hover 和书写；
- 退后台再回来；
- Pencil 双击工具切换（若产品要求）。

任何一项失败都要记录为 FAIL，并附截图/录屏/日志，不得用“实际落笔正确”替代 hover 通过。
