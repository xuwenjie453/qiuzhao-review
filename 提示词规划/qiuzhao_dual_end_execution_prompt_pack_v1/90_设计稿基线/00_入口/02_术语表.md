# 术语表

- **Question**：系统最基本业务元素；试题库问题或复习胶囊问题。
- **QuestionGraph**：围绕 Question 的稳定图；一个 CENTER + 0..N Explanation/Temporary。
- **Center Node**：问题节点，正方形，不得删除。
- **Explanation Node**：用户显式选中的 AI 解释，圆形，长期保留。
- **Temporary Node**：用户显式选中的临时解释，三角形，仅当前 Round 可见。
- **Question Round**：一次从“开始围绕某问题讨论”到“结束/切题”的讨论周期。
- **Active Question**：Mac Agent 当前正在讨论且已 `question.open` 的问题。
- **Node Body**：节点的 Markdown 正文；commit 后 immutable。
- **Node Title**：节点显示短标题；AI 初始生成，iPad 后续可编辑。
- **Ink**：与 node_id 绑定的 PencilKit `PKDrawing` 二进制数据。
- **Layout**：节点在问题图中的用户位置。
- **Snapshot**：某图某 revision 的完整可见状态。
- **Patch**：从 base_revision 到 target_revision 的增量变更。
- **Outbox**：iPad 已本地提交、待发往 Mac 的操作队列。
- **Inbox Dedup**：已应用 message_id 记录，防止重复副作用。
- **Daemon Stable ID**：同一 Mac DualEnd 安装的稳定身份。
- **Session Epoch**：一次网络连接会话的随机 UUID；重连必换。
