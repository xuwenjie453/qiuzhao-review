# 用户交互语义

## 1. Mac Agent 侧

下面语义是 Runtime Prompt 的硬规则。

### 不创建节点

- “这个解释挺重要的。”
- “我懂了。”
- “这个以后可能还会看。”

这些都不是明确入图指令。

### 创建长期 Explanation

- “把你刚才这个解释加到问题图。”
- “把第二段放到图里。”
- “这个解释保留下来。”（当上下文明显指向入图行为时）

Agent 必须识别具体 assistant content span，并原样传 body。

### 创建 Temporary

- “这个先临时放到图里。”
- “把刚才那个作为临时节点。”

## 2. iPad Topology

- Single tap：选中 node，打开轻量管理 popover/sheet。
- Long press + drag：进入拖动态，位置实时移动；手势结束 durable persist + outbox。
- Double tap：进入 Reader。

为了避免 single/double 冲突：single tap 行为延迟一个双击识别窗口，若识别为双击则取消单击管理。

## 3. 管理能力

CENTER：编辑标题；delete 按钮不显示。

EXPLANATION/TEMPORARY：编辑标题；delete 需要轻量确认（防止误触），但不要求密码/复杂流程。

## 4. Reader

- 手指：滚动页面、点击链接/选择 UI。
- Pencil：画笔。
- Pencil 双击：ink/eraser toggle。
- 正文不出现编辑光标。
