# 范围与非目标

## In Scope

- 问题图新领域模型。
- Mac 常驻 DualEnd daemon。
- Agent→daemon 本机命令接口。
- Bonjour 自动发现。
- WebSocket 长连接。
- iPad 本地缓存/离线可读。
- 图结构/标题/位置/删除同步。
- Markdown Reader。
- PencilKit Ink。
- Ink 持久化和 Mac 备份。
- 断线重连、Snapshot/Patch、幂等。
- 对现有 runtime prompt 增加双端行为契约。

## Explicit Non-goals v1

- 不在 iPad 上执行学习 Scheduler。
- 不在 iPad 上与 LLM 聊天。
- 不在 iPad 上编辑 Node Body。
- 不做跨 Question 的知识图谱边。
- 不允许 explanation→explanation 的语义关系编辑。
- 不做 CRDT/多人实时协同。
- 不做公网远程连接。
- 不做 iCloud 同步。
- 不做多 iPad 合并冲突优化；协议可容忍多个连接，但产品目标是单用户单 iPad。
- 不把原 `qiuzhao-review` 数据库迁移到 reading-system 的 Canonical Store。
- 不把 reading-system 的 Reading Scheduler / Interest/Timing 引入求职复习 Scheduler。
