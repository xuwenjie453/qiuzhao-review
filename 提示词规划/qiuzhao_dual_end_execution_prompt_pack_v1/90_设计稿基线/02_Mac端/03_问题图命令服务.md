# QuestionGraph Command Service

## 1. Query / Command 分离

Queries 无副作用：

- `graph.get(question_key)`
- `graph.snapshot(graph_id, round_id?)`
- `round.get_active()`
- `node.get(node_id)`
- `sync.status()`

Commands：

- `question.open`
- `question.close`
- `node.add`
- `node.rename`
- `node.move`
- `node.delete`
- `ink.put`

## 2. Command 通用字段

```text
command_id UUID       # caller idempotency
actor AGENT|IPAD
base_*_revision        # 针对具体变更域
payload
```

`command_id` 在 Mac `command_dedup` UNIQUE；重复提交返回第一次结果。

## 3. rename

输入 `node_id`, `title`, `base_node_revision`。

- CENTER 可 rename。
- title trim 后 1..80 Unicode scalar；
- body 不动；
- node_revision++；graph_revision++。

## 4. move

输入 `node_id`, `x_norm`, `y_norm`, `base_layout_revision`。

- x/y clamp 0..1；
- layout_revision++；
- graph_revision++；
- 不修改 node_revision。

## 5. delete

- CENTER -> `CENTER_DELETE_FORBIDDEN`；
- others -> tombstone；
- graph_revision++；
- ink 默认保留为 orphaned backup，不再下发。

## 6. ink.put

`ink_revision` 期望严格等于 server current + 1；重复 revision 且 hash 相同视为幂等成功；低 revision 忽略；跳 revision 返回 `INK_REVISION_GAP`，iPad 发送当前 full snapshot。
