# iPad 连接状态 UX

自动连接不等于隐藏状态。App 顶部可有轻量状态徽章：

- `已连接`
- `正在连接…`
- `离线 · 显示本地内容`
- `需要本地网络权限`
- `协议版本不兼容`

不提供：

- IP 输入框；
- 端口输入；
- 配对码输入；
- 常规场景下“选择 Mac”页面。

## 首次启动

在触发 iPadOS Local Network prompt 前，用一屏简短说明：“用于自动发现同一局域网中的 Mac 学习守护进程。”随后启动 NWBrowser 触发系统权限。

如果权限 denied：提供“打开系统设置”按钮。这个是系统权限恢复，不是连接配置。

## Mac 离线

显示 cache；Topology/Reader/Ink 都可用。只有从 Mac 新推送问题/解释不可达。
