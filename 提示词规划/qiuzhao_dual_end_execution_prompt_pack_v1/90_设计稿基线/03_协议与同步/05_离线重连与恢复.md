# 离线、重连与恢复

## 1. 离线原则

断开 Mac 后，iPad 不回空白首页。保留：

- 当前 graph；
- 所有已缓存 node body；
- layout；
- ink；
- 待同步 title/move/delete/ink outbox。

## 2. 本地优先操作

iPad 用户操作顺序：

```text
UI gesture
 -> local SQLite transaction
 -> update screen
 -> append outbox
 -> network sender attempts
```

## 3. 重连

```text
Bonjour rediscover
 -> WebSocket
 -> HELLO(last_server_seq, cached revision)
 -> WELCOME(new session_epoch)
 -> server decides replay possible? 
      yes: replay journal
      no: GRAPH_SNAPSHOT
 -> client durable apply
 -> replay local outbox in order
```

## 4. Active graph change

如果离线期间 Mac 已切题，重连后 server 的 WELCOME/ACTIVE_GRAPH_CHANGED 优先。iPad将新 active graph 导航为主界面；旧图仍留本地 cache，但不继续显示为“当前问题”。

## 5. Session epoch

任何旧 WebSocket session 的 ACK/conditional response 不可作用到新 epoch。虽然 v1 没有复杂自动导航条件，但保留 epoch 能杜绝延迟包跨连接污染状态。
