## 用户需求基线

- `秋招复习系统_双端更新_用户需求汇总.md`（本次上传，259 行）。本设计将其作为产品硬约束；未把此前助手自行扩展当成用户需求。

## 参考仓库

### qiuzhao-review

https://github.com/xuwenjie453/qiuzhao-review

当前 README 表明其仍是 Agent-native 秋招学习闭环：Goal Stack → Temporal Scheduler → Knowledge/Algorithms/Projects → Learning Events → Review Capsule；题库、资料库和多个 SQLite 有明确边界。本设计不替换这些机制。

### reading-system

https://github.com/xuwenjie453/reading-system

重点参考：

- `ReadingSystem-Mac/` daemon / state DB / Bridge；
- `ReadingSystem-iPad/` SwiftUI + PencilKit + SQLite + URLSessionWebSocketTask；
- Snapshot/Patch、revision、dedup、durable-before-ACK、offline/outbox；
- Bonjour 自动发现。

明确不照搬：reading-system 的 6 位配对码，因为用户要求零手动配对；不照搬书籍 Graph/Reading Scheduler 业务逻辑。
