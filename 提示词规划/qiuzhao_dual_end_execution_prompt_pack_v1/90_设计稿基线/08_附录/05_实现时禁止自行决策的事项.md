# 实现 AI 禁止自行改写的产品决策

以下事项已经由用户需求/本设计冻结，不应因为“更智能”而改掉：

1. 解释入图必须用户显式决定。
2. Temporary 下轮不得出现。
3. CENTER 不得删除。
4. iPad 不得改 body。
5. 问题图节点形状三分法固定。
6. Mac/iPad 连接不要求输入 IP/配对码。
7. iPad 是 Reader，不接管 Mac Agent 会话。
8. 本次不替换秋招 Scheduler/三引擎/Review 业务。
9. Ink 按 node_id 绑定，不按 title。
10. node body 一旦创建 immutable。
11. 参考 PDF 未提供时不得捏造“匹配值”。
12. 网络 ACK 必须在 durable commit 后。

如果实现发现技术问题导致必须改变其中任一项，应停止该分支实现并把冲突明确提出来，而不是静默降级。
