```json
{"v":1,"message_id":"m1","type":"HELLO","session_epoch":null,"sent_at":"...","payload":{"device_id":"ipad-A","supported_protocols":[1],"last_server_seq":0,"cached_graph":null}}
```

## 2. Mac WELCOME

```json
{"v":1,"message_id":"m2","type":"WELCOME","session_epoch":"e1","sent_at":"...","payload":{"selected_protocol":1,"daemon_id":"mac-A","server_seq":0,"active":null}}
```

## 3. Agent question.open 后 Mac push

```json
{"v":1,"message_id":"m3","type":"GRAPH_SNAPSHOT","session_epoch":"e1","sent_at":"...","payload":{"graph_id":"g1","question_key":"qb:Redis-01-003","round_id":"r1","revision":1,"center_node_id":"n0","nodes":[{"node_id":"n0","kind":"CENTER","title":"Redis过期删除策略","body_markdown":"原题干","node_revision":1,"layout":{"x":0.5,"y":0.5,"revision":1}}]}}
```

## 4. Agent add explanation

Patch：

```json
{"v":1,"message_id":"m4","type":"GRAPH_PATCH","session_epoch":"e1","sent_at":"...","payload":{"graph_id":"g1","base_revision":1,"target_revision":2,"ops":[{"op":"ADD_NODE","node":{"node_id":"n1","kind":"EXPLANATION","title":"惰性与定期删除","body_markdown":"...原解释...","node_revision":1,"layout":{"x":0.7,"y":0.4,"revision":1}}}]}}
```

## 5. iPad drag

```json
{"v":1,"message_id":"m5","type":"CLIENT_COMMAND","session_epoch":"e1","sent_at":"...","payload":{"command_id":"c1","kind":"MOVE_NODE","graph_id":"g1","payload":{"node_id":"n1","x_norm":0.82,"y_norm":0.31,"base_layout_revision":1}}}
```
