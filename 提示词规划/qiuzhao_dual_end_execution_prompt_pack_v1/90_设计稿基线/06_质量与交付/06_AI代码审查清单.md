# AI 代码审查清单

实现 AI 在每个 PR/patch 后自查：

## Domain

- 是否出现任何“自动把重要解释加入图”的逻辑？有则删除。
- 是否可能更新 node body？有则违反设计。
- 是否存在 CENTER delete path？client/server 都检查。
- temp 是否明确绑定 round？

## Sync

- ACK 前是否已 commit？
- dedup 是否 transaction 内完成？
- graph patch 是否校验 base revision？
- reconnect 是否重放 outbox？
- message handler 是否可重入/重复？

## iPad

- 网络 callback 是否直接写 SwiftUI state 而绕 Store？
- Pencil drawing save 是否在 MainActor 做重 I/O？
- Reader 是否存在两个独立滚动坐标导致 Ink 漂移？
- title/edit/delete 是否在离线时仍工作？

## Scope

- 是否意外修改 Scheduler/FSRS/Goal 算法？若没有明确必要，回滚。
- 是否引入 Web/App 学习主流程？iPad 仅 reader，不接管学习会话。
