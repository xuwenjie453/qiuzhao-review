# 测试策略

## 1. Mac unit

- graph identity stable；
- one center invariant；
- body immutable trigger；
- center delete reject；
- temp round filter；
- command dedup；
- per-node/layout revision CAS；
- ink revision；
- journal server_seq monotonic。

## 2. Protocol contract

使用固定 JSON fixtures，Node decoder 与 Swift decoder 都跑：

- HELLO/WELCOME；
- SNAPSHOT；
- PATCH；
- CLIENT_COMMAND；
- INK_PUT；
- error。

任何协议字段改动必须同步更新两端 fixtures。

## 3. Mac bridge E2E

写 Node test 模拟 iPad：

1. connect；
2. hello；
3. open question；
4. receive snapshot；
5. add explanation；
6. receive patch；
7. duplicate ack/message；
8. reconnect；
9. revision mismatch recovery。

## 4. iPad unit

- ClientStore transaction；
- outbox replay；
- snapshot replace；
- patch validation；
- node gesture state reducer；
- title/delete optimistic update rollback。

## 5. UI tests

- CENTER square；Explanation circle；Temporary triangle；
- single/double/long-press gestures 不串扰；
- previous temporary absent on new round；
- cache offline opens Reader。

## 6. 真机 Pencil Gate

模拟器不算 Pencil 性能验收。必须真实 iPad + Apple Pencil：

- low-latency handwriting；
- double tap eraser（支持该能力的 Pencil 型号）；
- long page scroll while ink remains aligned；
- background/kill/relaunch ink persistence。
