# Release Acceptance Criteria

## A. Question-first

- [ ] 试题库问题可 open 成 graph。
- [ ] Review Capsule 问题可 open 成 graph。
- [ ] 同 question_key 重开得到同 graph_id。

## B. User-controlled explanations

- [ ] Agent 普通解释不会自动创建 node。
- [ ] 用户显式指令可创建 Explanation。
- [ ] 用户显式指令可创建 Temporary。
- [ ] node body 与用户指定的原解释一致。

## C. Topology

- [ ] CENTER 正方形且不可删除。
- [ ] Explanation 圆形。
- [ ] Temporary 三角形。
- [ ] title 位于节点上方。
- [ ] long press drag 持久化。
- [ ] double tap 进入 Reader。
- [ ] single tap 能 rename/delete（按类型限制）。

## D. Round

- [ ] close 后 temporary 从当前图移出。
- [ ] 再次打开同题不会出现上一轮 temporary。
- [ ] persistent explanation 仍存在。

## E. Reader / Ink

- [ ] Markdown 正常渲染。
- [ ] 长页纵向滚动。
- [ ] iPad 无正文编辑入口。
- [ ] Pencil 直接书写。
- [ ] 支持 Pencil double tap 的设备可切 eraser。
- [ ] relaunch/reopen node 笔迹存在。
- [ ] Ink 对正文无可见漂移。
- [ ] 排版匹配参考 PDF：`BLOCKED` 直到 PDF 可用。

## F. Zero-config LAN

- [ ] daemon + iPad 同 LAN 自动发现。
- [ ] 自动连接。
- [ ] 无 IP 输入。
- [ ] 无配对码。
- [ ] Wi-Fi 断开恢复后自动重连。

## G. Reliability

- [ ] duplicate message one effect。
- [ ] patch revision mismatch snapshot recover。
- [ ] iPad durable before ACK。
- [ ] Mac durable before emit/ACK。
- [ ] daemon crash 后 canonical graph 不损坏。
