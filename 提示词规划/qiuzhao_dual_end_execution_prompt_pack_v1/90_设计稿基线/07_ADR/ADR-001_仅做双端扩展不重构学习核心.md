# ADR-001：仅做双端扩展，不重构学习核心

Status: Accepted

## Context

当前 `qiuzhao-review` 已有完整 Goal/Scheduler/三引擎/Review 闭环。用户明确本次“只是做双端更新，将 iPad 纳入”。

## Decision

新增独立 DualEnd subsystem；旧学习系统通过 Agent command 集成。

## Consequences

优点：风险小、可增量上线、学习状态不迁移。

代价：Mac 端存在 Python Learning Core + 新 daemon 两种 runtime；这是接受的边界，而不是暂时 hack。
