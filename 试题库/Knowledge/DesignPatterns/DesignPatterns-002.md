### DesignPatterns-002-001 | ★★★☆☆

请说说责任链模式。（华为OD一面原题）

**答案：**
行为型模式，请求沿处理者链传递，每个处理者决定处理或转发给下一个；典型应用如日志级别处理、过滤器链、拦截器。


### DesignPatterns-002-002 | ★★★☆☆

说下工厂模式，并结合场景说明。（华为一面原题）

**答案：**
简单工厂/工厂方法/抽象工厂，将对象创建逻辑封装，客户端只依赖接口；场景如支付渠道、消息推送器按类型创建。


### DesignPatterns-002-003 | ★★★☆☆

单例模式的好处有哪些？（腾讯暑期实习一面原题）

**答案：**
节省内存（全局唯一实例）、避免频繁创建销毁开销、提供全局访问点便于共享资源（如配置、连接池）。


### DesignPatterns-002-004 | ★★★☆☆

讲讲单例模式有哪些情况（饿汉和懒汉），具体该如何使用？（美团暑期实习一面原题）

**答案：**
饿汉类加载即创建（天生线程安全，可能浪费）；懒汉首次使用才创建（需处理线程安全：DCL+volatile、静态内部类、枚举）。


### DesignPatterns-002-005 | ★★★☆☆

单例模式有几种实现方式？最常用的实现方式是哪种？为什么？（字节跳动Java后端一面原题）

**答案：**
常用静态内部类（利用类加载机制保证线程安全且懒加载）或枚举（防反射破坏、防反序列化）。


### DesignPatterns-002-006 | ★★★☆☆

手写单例模式，各种情况，怎么保证线程安全？（腾讯云智一面原题）

**答案：**
手写DCL：private static volatile Singleton instance; 双重 if(instance==null) 加 synchronized；或静态内部类/枚举。


### DesignPatterns-002-007 | ★★★☆☆

单例模式如何保证线程安全？（携程Java暑期实习一面原题）

**答案：**
饿汉/静态内部类由JVM类加载保证；懒汉需synchronized+双重检查+volatile（防指令重排）；枚举天然安全。


### DesignPatterns-002-008 | ★★★☆☆

了解哪些设计模式？（字节跳动Java后端一面原题）

**答案：**
创建型（单例、工厂、建造者）、结构型（代理、适配器、装饰器）、行为型（策略、模板、责任链、观察者），结合Spring场景说明。


### DesignPatterns-002-009 | ★★★☆☆

你真正在项目中使用过哪些设计模式？（奇安信Java技术一面原题）

**答案：**
结合真实项目讲2-3个即可，典型如：策略+工厂消除if-else分支、单例管理配置/连接池、观察者/发布订阅做事件解耦、模板方法固定流程骨架、代理做日志与权限控制。重点讲清使用场景与带来的收益，而非罗列模式名。


### DesignPatterns-002-010 | ★★★☆☆

什么是开闭原则？（vivo技术一面原题，追问设计模式时考察）

**答案：**
对扩展开放、对修改关闭；通过抽象（接口/抽象类）与多态，新增行为通过扩展实现而非修改原有代码。


### DesignPatterns-002-011 | ★★★☆☆

业务代码里 if else 过多怎么解决？（微众银行Java后端一面原题）

**答案：**
策略模式+工厂/注册表替换分支、Map+函数式接口、责任链、卫语句提前返回等。


### DesignPatterns-002-012 | ★★★☆☆

什么是策略模式？你在自己的代码里用过什么设计模式？（美团一面原题）

**答案：**
定义一族可互相替换的算法封装，运行时选择；常用于替代多重if-else（优惠计算、支付路由、AI服务切换等）。


### DesignPatterns-002-013 | ★★★☆☆

模板模式在 Java 中具体怎么实现的？（京东JDS面试原题）

**答案：**
抽象类定义算法骨架（final模板方法），子类实现差异步骤；典型如JdbcTemplate、AQS、Servlet的service/doGet。


### DesignPatterns-002-014 | ★★★☆☆

【场景设计题】要做一个数据导出功能，导出格式可能是 Excel、JSON、XML，如果用面向对象的方法去做，你会怎么设计实现？

**答案：**
定义统一导出接口（如Exporter的export(data)），每种格式一个实现类，配合工厂按类型创建实例；新增格式只需加实现类（开闭原则）。
