### Git-002-001 | ★★★☆☆

git rebase和git merge的区别是什么？

**答案：**
merge保留分支历史产生合并提交（非线性），rebase把当前分支提交搬到目标分支之后形成线性历史；黄金法则：已推送的公共分支不要rebase。

git merge <branch>合并；冲突时git会在文件中标出<<<<<<< ======= >>>>>>>，手动编辑保留正确内容后git add再commit完成合并。


### Git-002-003 | ★★★☆☆

Git有哪几个工作区域？它们之间是怎么流转的？

**答案：**
工作区、暂存区(index)、本地仓库、远程仓库；add把改动从工作区加到暂存区，commit提交到本地仓库，push推到远程，fetch/pull拉回。


### Git-002-004 | ★★★☆☆

git pull和git fetch有什么区别？git pull和git pull --rebase的区别是什么？

**答案：**
fetch只拉取远程更新不合并，pull = fetch + merge（或 --rebase 时拉取后变基，保持线性历史避免多余merge commit）。


### Git-002-005 | ★★★☆☆

什么是HEAD？什么是游离HEAD（detached HEAD）？

**答案：**
HEAD是指向当前分支引用的指针；checkout到某个commit而非分支时处于detached HEAD，此时提交不属于任何分支、切走后易丢失，需新建分支保存。


### Git-002-006 | ★★★☆☆

git reset的--soft、--mixed、--hard三种模式有什么区别？git reset和git revert的区别是什么？

**答案：**
--soft只移动HEAD保留暂存区，--mixed（默认）重置暂存区保留工作区，--hard全部重置丢弃改动；reset回退历史（改写已有提交，公共分支危险），revert生成反向提交安全地撤销变更。


### Git-002-007 | ★★★☆☆

git commit --amend是做什么的？什么时候用？

**答案：**
修改最近一次提交（改信息或补文件）；适合本地未推送时修补提交，公共分支勿用。


### Git-002-008 | ★★★☆☆

git stash是做什么用的？常用命令有哪些？

**答案：**
把工作区未提交改动暂存起来以便切分支；git stash save/pop/apply/list/drop。


### Git-002-009 | ★★★☆☆

不小心把敏感信息（密码、密钥）提交到Git怎么办？

**答案：**
立即吊销该密钥（视为泄露）；用git filter-repo/BFG清理历史并强推，同时通知协作方重新clone。


### Git-002-010 | ★★★☆☆

git cherry-pick是做什么的？什么场景用？

**答案：**
把某个（些）提交复制应用到当前分支；常用于把修复提交挑选到release分支。


### Git-002-011 | ★★★☆☆

.gitignore里加了文件为什么不生效？

**答案：**
已被git跟踪的文件ignore规则不生效，需git rm --cached移除跟踪后重新提交。


### Git-002-012 | ★★★☆☆

什么是Fast-Forward合并？和普通merge有什么区别？

**答案：**
目标分支是当前分支祖先时直接把指针前移、不产生合并提交；普通merge会基于两分支最新快照创建merge commit。


### Git-002-013 | ★★★☆☆

如何删除本地分支和远程分支？

**答案：**
git branch -d <name>（未合并需-D强制），git push origin --delete <name>。


### Git-002-014 | ★★★☆☆

常见的Git工作流有哪些？Fork、Clone、Pull Request在GitHub协作中分别是什么？

**答案：**
常见Git Flow、GitHub Flow、Trunk Based；Fork把仓库复制到自己账号下，Clone拉取到本地，Pull Request请求把分支合回上游仓库的开源协作流程。


### Git-002-015 | ★★★☆☆

git tag有什么用？轻量标签和附注标签有什么区别？

**答案：**
tag给特定提交打标签（常用于版本发布）；轻量标签只是指向提交的引用，附注标签（-a）是含作者/日期/说明的独立对象并可直接推送。


### Git-002-016 | ★★★☆☆

git blame和git bisect分别是做什么的？

**答案：**
blame查看文件每行最后的修改者与提交；bisect二分定位引入bug的提交（好/坏标记自动缩小范围）。
