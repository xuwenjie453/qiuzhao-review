### SQL-002-001 | ★★★★☆

row_number、rank、dense_rank 这三个窗口函数的区别是什么？

**答案：**
row_number严格递增不重复；rank并列同名次但跳号（1,1,3）；dense_rank并列不跳号（1,1,2）。


### SQL-002-002 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询每个用户的订单数量和总金额。

**答案：**
SELECT user_id, COUNT(*) AS order_cnt, SUM(amount) AS total_amount FROM orders GROUP BY user_id;


### SQL-002-003 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询每个用户最后一次下单的时间。

**答案：**
SELECT user_id, MAX(created_at) AS last_order_time FROM orders GROUP BY user_id;（取每个用户组内最大下单时间即可）


### SQL-002-004 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询最近7天每天的新增用户数。

**答案：**
SELECT DATE(created_at) AS dt, COUNT(*) FROM users WHERE created_at >= DATE_SUB(CURDATE(), INTERVAL 7 DAY) GROUP BY DATE(created_at);（按用户注册时间字段分组统计）


### SQL-002-005 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询销售额最高的前3个城市。

**答案：**
SELECT u.city, SUM(o.amount) AS sales FROM orders o JOIN users u ON o.user_id=u.id GROUP BY u.city ORDER BY sales DESC LIMIT 3;


### SQL-002-006 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询从未下单的用户。

**答案：**
SELECT * FROM users WHERE id NOT IN (SELECT DISTINCT user_id FROM orders); 或 LEFT JOIN 后筛 o.id IS NULL。


### SQL-002-007 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询每月销售额的同比增长率。

**答案：**
先按月聚合 SUM(amount)，再自关联取去年同期或用 LAG(月销售额, 12) OVER(ORDER BY 月份)，同比 = (本月-去年同期)/去年同期。


### SQL-002-008 | ★★★★☆

【SQL笔试】有用户表 users(id, name, age, gender, city)，订单表 orders(id, user_id, amount, created_at)。查询每个城市的男女人数。

**答案：**
SELECT city, gender, COUNT(*) FROM users GROUP BY city, gender;


### SQL-002-009 | ★★★★☆

【SQL手撕】学生成绩表，查找一个学生两门功课都大于80分的姓名。

**答案：**
SELECT name FROM score GROUP BY name HAVING MIN(score)>80 AND COUNT(DISTINCT subject)>=2; 或用自连接/两门科目分别>80筛选。


### SQL-002-010 | ★★★★☆

【SQL手撕】查询一个城市列表（表）里面重复的城市名，并且统计重复次数。

**答案：**
SELECT city, COUNT(*) AS cnt FROM t GROUP BY city HAVING COUNT(*)>1;


### SQL-002-011 | ★★★★☆

【SQL手撕】查找学生成绩表中平均分数大于90分的学生名单。

**答案：**
SELECT name FROM score GROUP BY name HAVING AVG(score)>90;


### SQL-002-012 | ★★★★☆

【SQL手撕】查找学生成绩表中平均成绩最高的同学。

**答案：**
SELECT name FROM score GROUP BY name ORDER BY AVG(score) DESC LIMIT 1;
