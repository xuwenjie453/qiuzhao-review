### MachineLearning-001-001 | ★★★★☆

监督学习和无监督学习的区别？

**答案：**
监督学习的训练数据**带标签**（每个样本有正确答案），学的是"输入→输出"的映射，任务分分类（输出离散：垃圾邮件识别）与回归（输出连续：房价预测），代表算法逻辑回归、决策树、神经网络；无监督学习数据**无标签**，自己发现数据内在结构，典型任务聚类（KMeans、用户分群）、降维（PCA）、关联规则。中间还有半监督（少量标注+大量未标注）与自监督（从数据自身构造监督信号——大模型预训练就是自监督的"下一个词预测"）。一句话判别：有没有"标准答案"参与训练。

**解析：**
工程语境对应：有历史标注数据的风控评分（监督）、客户分群营销（无监督）、LLM 预训练（自监督）+ 人类反馈对齐（监督/强化）。选择路径：有标注数据且目标明确→监督；无标注要探索结构→无监督；标注昂贵→半监督/主动学习。


### MachineLearning-001-002 | ★★★★☆

什么是过拟合和欠拟合？怎么解决？

**答案：**
过拟合：训练集表现很好、测试集/新数据明显差——模型把训练数据的噪声也背下来了，泛化能力差；欠拟合：训练集和测试集都差——模型太简单或训练不足，连规律都没学到。诊断看训练/验证误差的组合：双高=欠拟合，训练低验证高=过拟合。解决过拟合：更多数据、正则化（L1/L2）、Dropout（神经网络）、早停、降低模型复杂度、数据增强、交叉验证选超参；解决欠拟合：增强特征、提高模型复杂度、减小正则化强度、训练更久。

**解析：**
与 Bias/Variance 对应：欠拟合=高偏差（模型假设太简单，系统性偏离真实规律），过拟合=高方差（对训练集敏感，换批数据结果波动大）。权衡是"偏差-方差权衡"：模型复杂度从低到高，偏差单调降、方差单调升，总误差先降后升，最优点在中间。正则化直觉：L2（权重衰减）惩罚大权重让函数更平滑，L1 产生稀疏解（天然特征选择）。


### MachineLearning-001-003 | ★★★★☆

训练集、验证集、测试集的区别？交叉验证是什么？

**答案：**
三份数据三种用途：训练集拟合参数；验证集选超参/选模型/调阈值（不参与参数训练）；测试集只在最后做一次性的泛化评估（绝不能反过来影响选择）。交叉验证（如 k 折）：把训练数据分 k 份，轮流用 k-1 份训练、1 份验证，取平均——让每个样本都参与验证，评估更稳，常用于小数据集选模型；数据少用 5/10 折，数据充足时简单留出法即可。注意纪律：测试集泄漏（预处理统计量用了测试集信息、测试集参与调参）是数据科学最常见的造假性错误。

**解析：**
时间序列数据的特殊性：随机 k 折会造成"用未来预测过去"的泄漏，要用滚动/时间切分验证——面试点出这一条很加分。分层采样：分类问题各折保持类别比例（StratifiedKFold）。


### MachineLearning-001-004 | ★★★★☆

Precision、Recall、F1 是什么？什么场景看重哪个？

**答案：**
针对二分类的正类而言：混淆矩阵四格 TP（真阳）、FP（假阳）、FN（假阴）、TN（真阳）。Precision = TP/(TP+FP)——预测为正的里面有多少真的是正（查准率），报出来的准不准；Recall = TP/(TP+FN)——所有真正的正例里抓出了多少（查全率），该抓的漏没漏。两者天然此消彼长（阈值移动），F1 是调和平均：F1 = 2PR/(P+R)，偏向惩罚"某一项极低"。场景取舍：风控/欺诈检测更看重 Recall（漏掉欺诈损失大），可接受误报再人工复核；垃圾邮件拦截更看重 Precision（误杀正常邮件代价大）；医疗确诊重 Recall。多分类有宏平均（每类等权）与微平均（按样本量加权）之分。

**解析：**
典型计算（笔试）：100 个样本中正类 20 个，模型预测出正类 30 个，其中 18 个正确 → P = 18/30 = 0.6，R = 18/20 = 0.9，F1 = 2×0.6×0.9/(1.5) = 0.72。阈值移动的直觉：调高判定阈值→更保守→P 升 R 降。不平衡数据的坑：99% 负样本时"全预测负"准确率 99% 但 Recall=0——所以不平衡场景看 P/R/F1/PR-AUC 而非准确率。


### MachineLearning-001-005 | ★★★★☆

ROC 曲线和 AUC 是什么？

**答案：**
ROC 曲线以阈值从 1 到 0 滑动，横轴假阳率 FPR = FP/(FP+TN)，纵轴真阳率 TPR（=Recall），画出各阈值下的点连成曲线；AUC 是曲线下面积，含义是"随机取一个正样本和一个负样本，模型给正样本打分更高的概率"。AUC=0.5 等于随机猜，1 是完美，0.7~0.8 可用、0.8~0.9 良好。优点：对类别分布变化不敏感（阈值无关、比例无关），适合评估排序质量与不平衡数据；对比 PR 曲线：类别极不平衡且更关注正类查准/查全时 PR 曲线更敏感。

**解析：**
AUC 的排序本质给出一个工程直觉：如果业务只需要"按风险分排序取 top-k"（名单制营销、风控名单），AUC 是正确指标；如果需要固定阈值做"通过/拒绝"决策，还要结合 KS（最大分离度）与业务代价。多分类 AUC 用 one-vs-rest 宏平均。


### MachineLearning-001-006 | ★★★★☆

逻辑回归的原理？为什么叫"回归"却做分类？

**答案：**
逻辑回归 = 线性回归的输出套 Sigmoid 函数：z = w·x + b，p = 1/(1+e^(-z))，把任意实数映射到 (0,1) 解释为"属于正类的概率"，按阈值（默认 0.5）分类。它优化的是对数损失（交叉熵），用梯度下降求解；输出的是概率而非硬标签，因此天然支持阈值调节与风险排序。名字里带"回归"是因为它在回归 f(x) 的对数几率（logit），属于广义线性模型。优点：简单、可解释（权重即特征影响方向与幅度）、训练快、输出概率；缺点：线性决策边界（需特征工程/多项式特征处理非线性）、特征共线敏感。金融评分卡至今主流用它，就是因为系数可解释、合规能讲清。

**解析：**
决策边界是 w·x+b=0 的超平面；Sigmoid 单调保证概率排序与 z 排序一致。损失：交叉熵 -[y·log p + (1-y)·log(1-p)]，比均方误差在 Sigmoid 下有更好的梯度性质（无局部饱和导致的梯度消失问题）。特征处理：连续特征分箱/标准化，类别特征 one-hot，共线特征剔除或正则化。


### MachineLearning-001-007 | ★★★★☆

决策树、随机森林、GBDT/XGBoost 是什么关系？

**答案：**
三者是"一棵树 → 多棵树并行 → 多棵树串行"的演进。决策树：按特征逐层分裂（选优标准：信息增益/信息增益率/基尼系数），可解释性强，但单树容易过拟合、不稳定；剪枝对抗过拟合。随机森林（Bagging）：有放回采样训练多棵树+节点分裂时随机选特征子集，结果投票/平均——并行、抗过拟合、方差降低；GBDT/XGBoost（Boosting）：串行训练，每棵新树拟合前面所有树的**残差/梯度**，逐步纠错——偏差降低，精度通常更高但对噪声敏感、需调参防过拟合。XGBoost 在 GBDT 基础上加二阶泰勒展开、正则项、列采样与工程优化；LightGBM 进一步用直方图算法提速。经验：表格类结构化数据上这类树模型的竞争力至今仍强于深度学习。

**解析：**
Bagging vs Boosting 对比表：训练方式（并行独立 vs 串行依赖）、目标（降方差 vs 降偏差）、样本权重（等权 vs 误分加权）、代表（RF vs GBDT/XGB/LightGBM）、基学习器（强而深的树 vs 弱学习器）。特征重要性：树模型天然输出（分裂增益/频次），SHAP 提供逐样本归因——可解释机器学习的工程抓手。


### MachineLearning-001-008 | ★★★★☆

KMeans 聚类和 PCA 降维的原理？

**答案：**
KMeans：无监督聚类。流程：①指定 k，随机选 k 个初始中心；②每个样本归入最近中心；③按簇内均值更新中心；④重复②③直到收敛。关键点：对初值敏感（KMeans++ 改进初始化）、需预设 k（肘部法/轮廓系数选择）、只能发现凸形（球状）簇、对量纲敏感（必须标准化）。PCA 主成分分析：无监督线性降维，找数据方差最大的正交方向投影，保留主要信息压缩维度；用途：可视化、去共线、降噪、加速下游训练；步骤：中心化→协方差矩阵→特征分解→取前 k 大特征向量投影。两者都要求先做特征标准化。

**解析：**
KMeans 复杂度 O(nkt·d)；收敛到局部最优所以多次随机重启。PCA 的"方差即信息"假设：主成分按解释方差比排序，累计贡献率（如 95%）决定保留维度。工程关联：embedding 向量（如 K-VEC-001）做 KMeans 即用户/文档聚类，PCA/UMAP 用于向量可视化——AI 应用工程里直接复用。

### MachineLearning-001-010 | ★★★★★

B. 可以增加训练数据或数据增强

### MachineLearning-001-011 | ★★★★★

Precision/Recall 计算

某欺诈检测模型在 1000 笔交易（其中真实欺诈 50 笔）上预测出 80 笔"欺诈"，其中 40 笔确实为欺诈。该模型的召回率（Recall）为：

A. 50%
B. 80%
C. 40%
D. 5%

**答案：** B

**解析：**
- A：错误。50% = 40/80，这是**精确率**（Precision，预测为欺诈中真欺诈的比例）的口径，与召回率混淆。
- B：正确。Recall = TP/(TP+FN) = 40/(40+10) = 80%，即 50 笔真实欺诈中找出了 40 笔。
- C：错误。40% 无任何口径对应，属凑数干扰项。
- D：错误。5% = 50/1000 是数据集中欺诈的先验占比，与模型表现无关。

Recall 分母是"真实正类总数"，Precision 分母是"预测正类总数"；本题 Precision = 40/80 = 50%，Recall = 80%，F1 = 2×0.5×0.8/1.3 ≈ 0.615。

### MachineLearning-001-018 | ★★★★☆

正则化作用

在损失函数中加入 L1 正则化项的主要效果是：

A. 使部分权重变为 0，产生稀疏解，起到特征选择作用

**解析：**
- A：正确。L1（绝对值惩罚）的几何形状使最优解容易落在坐标轴上，产生稀疏权重。
- B：错误。"整体缩小但不为 0"是 L2（权重衰减）的效果。
- C：错误。正则化以牺牲训练精度为代价换取泛化，方向相反。
- D：错误。消除量纲是标准化的职责，与正则化无关。

L1 稀疏/特征选择，L2 平滑/权重缩小；正则化是抗过拟合手段。


### MachineLearning-001-019 | ★★★☆☆

PCA 的性质

关于主成分分析（PCA），下列说法正确的有：

A. 主成分是原始特征的线性组合
B. 第一主成分方向是数据方差最大的方向
C. PCA 属于有监督的降维方法，需要标签指导
D. 做 PCA 前通常要对特征进行中心化（必要）与标准化（建议）

**答案：** A、B、D

**解析：**
- A：正确。每个主成分是各原始特征的线性组合（载荷向量）。

- D：正确。中心化是数学前提，标准化避免大量纲特征主导方差。

### MachineLearning-001-021 | ★★★☆☆

决策树分裂指标

决策树选择分裂特征时，信息增益（ID3）的缺陷是：

B. 倾向于选择取值数目多的特征（如唯一 ID 类特征）

D. 不支持离散特征

### MachineLearning-001-024 | ★★★★★

C. 80%、67%
D. 67%、80%

**答案：** B

**解析：**
